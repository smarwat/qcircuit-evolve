Two exact parity facts let me drop bit 0 from the comparator and from the value subtraction. Expected at n=32: T ≈ 34,420 (down from 35,056), Q = 259 unchanged, so T*Q ≈ 8.91M.

**Subtraction.** The subtraction only fires when h1 = 1, meaning both values are odd. Writing v = 2v'+1 and u = 2u'+1 gives (v − u) mod 2^w = 2·((v' − u') mod 2^(w−1)). So the controlled subtract runs only on bits 1..w−1. Bit 0 is cleared with a plain `cx(h1, V0)`, since V0 = 1 whenever h1 = 1. This saves 3 Toffolis per iteration.

**Comparator.** The comparator's result is only used under h1, and then U0 = 1 and ~V0 = 0. So the carry out of bit 0 is exactly the incoming tie-break carry sp. The majority chain therefore starts at bit 1 with carry-in sp. When w = 1, the carry is sp itself, so the two `ccx(h1, sp, sc)` gates would cancel and both are skipped. This saves 2 Toffolis per iteration.

Both rewrites are exact identities for every input, so the circuit computes the same function as the parent.
