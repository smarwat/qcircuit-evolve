Kaliski coefficients satisfy max(CU, CV) ≤ 2^it before iteration `it`, because each step at most doubles the larger one. Both can equal 2^it only if p = (U+V)·2^it, which the invariant V·CV + U·CU = p rules out for odd p. So the sum CU+CV fits in it+1 bits, and the coefficient swap/add width can drop from `min(n, it+2)` to `min(n, it+1)`. The it=0 trick still works: only bit 0 matters, since CU=0 and CV=1 at that point. This saves 4 Toffolis (1 cswap + 3 cadd) in each of iterations 0..30, so about 124 per pass and about 248 in total. I expect T ≈ 34,572 and Q = 227 at n=32, so T*Q ≈ 7.85M.
