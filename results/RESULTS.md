Reading the table: with Hadamards every input has weight 1/2ⁿ, including the don't-care inputs 0 and p..2ⁿ−1 whose outputs the task leaves unspecified, so the expected probability on correct (a, a⁻¹ mod p) pairs is (p−1)/2ⁿ; ⟨ΣZ⟩ covers every branch, don't-cares included. At n = 4 the valid-input superposition is also run (expected probability 1). At n = 8 only the Hadamard preparation is run; a second preparation would repeat an hour-long simulation.

**Harness problems found and fixed during verification (disclosed in full).** The first n = 4 quantum run reported probability 0 on the correct pairs although every basis-state check passed. A reversible classical circuit is a permutation of basis states, so that combination is impossible for the circuit itself; the cause was in the harness. (1) With Qiskit Aer 0.18.0's `matrix_product_state` method, `save_amplitudes` returned zeros after long circuits and `initialize` produced wrong output distributions; a 14-qubit random reversible circuit compared against the exact statevector method reproduces both. (2) Our code read `save_probabilities_dict` with hex-string keys while this version returns integer keys. The verifier now prepares the valid-input state with compiled u/cx gates, avoids both primitives, reads either key type, and runs the self-test above before any quantum check. The first run's shots were already consistent with a correct circuit (every valid input gave its inverse, every ancilla read 0); nothing about the circuit changed.

**Accounting differences.**

- Computes the Montgomery inverse x^-1·2^n mod p of an input in Montgomery form (Sec. 3.4).
- Input preserved; result XOR-ed into a fresh n-qubit register; full Bennett uncompute (Sec. 3.4, Table 1 caption).
- Qubit total includes the n input and n output qubits (Table 1 'total' column).
- Fixed 2n rounds with a counter: constant-time, input-independent gate sequence (Sec. 3.4).
- Designed to minimise qubits first, then Toffolis (Sec. 5); constant adders use dirty-ancilla incrementers, hence the log n factor.
- Same function as RNSL: Montgomery inverse x^-1·2^n mod p; input preserved (2n in/out qubits in Table 4); Bennett uncompute; 2n fixed rounds (Sec. 4.2).
- Costs are T-counts, not Toffoli counts: AND = 4 T, AND† = 0 T (measurement-based), Toffoli = 7 T (Sec. 2).
- Formulas are linear-regression fits to Q# resource counts for every n from 4 to 64 plus 110-521 bits; only the leading term was fitted (Appendix D), so n=32 lies inside the data but the constant terms are approximate.
- Improves RNSL by performing each round's operations once with controlled swaps and correcting the pseudo-inverse in parallel during uncomputation (Sec. 4.2).
- Ours: plain inverse a⁻¹ mod p (not Montgomery form), so any 2^k correction is inside our count; input preserved; output in a fresh register; all ancillas returned to 0 (full uncompute); fixed, input-independent gate sequence (it is a circuit generated from n and p only); qubits = distinct qubits touched including the 2n input/output qubits; Toffolis counted exactly from the gate list, not fitted.
- Ours is evaluated only at n ≤ 32 (exhaustively for n ≤ 16); the published formulas target cryptographic sizes (n = 256-521) and were fitted or estimated there.

## Surprises

- 3 of 17 calls returned a program already in the archive (in redesign mode the model sometimes resubmitted an inspiration verbatim). The duplicate check caught them before evaluation; a prompt line forbidding resubmission would recover those calls.
- The winner's cost depends on p, not only on n: over n = 8..32, T/n² averages 32.12 for Mersenne primes p = 2ⁿ−1 (n = 13, 17, 19, 31) versus 34.51 for the other primes, because the generator sets its iteration count from bitlen(p·(p−1)) and specialises constants to p's bits. Together with lower-order effects at small n, this is why a single quadratic in n fits T only to within 18% (the log-log slope over n = 16..32 is 1.99).
- The winner's qubit count is exactly Q(n) = 7n + 3 (fit error 0.0%), the same leading coefficient as RNSL's qubit-minimised 7n + 2⌈log₂ n⌉ + 9, although the search optimised T·Q rather than qubits.
- The model predicted its own T and Q at n=32 by hand in every lineage reply, without running anything (the replies say so); the predictions were close throughout and exact for the last two steps.
- The winner computes in place in the input register (the contract allows it, since the reverse pass restores it) and parks late history bits in input qubits that are provably zero by then; the prompt only suggested generic register reuse.
- No candidate in this run failed the hidden verify tier; every failure was caught earlier, by the normal tier, the syntax check or the duplicate check.
